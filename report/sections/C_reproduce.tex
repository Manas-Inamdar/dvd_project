\section{Reproducing the results}
From a clean checkout, with ngspice installed and \texttt{NGSPICE\_EXE} set:
\begin{verbatim}
python -m venv .venv ; .venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe scripts\00_check_env.py
.venv\Scripts\python.exe scripts\01_generate_transistor_data.py     # 4 datasets x 10,000 rows
.venv\Scripts\python.exe scripts\02_data_check.py                   # Kirchhoff, distributions, trend plots
.venv\Scripts\python.exe scripts\03_train_compare_models.py         # model comparison on validation
.venv\Scripts\python.exe scripts\04_select_and_evaluate.py          # chosen models, test metrics, plots
.venv\Scripts\python.exe scripts\05_learning_curves.py
.venv\Scripts\python.exe scripts\12_build_report_tables.py          # regenerate report tables
\end{verbatim}
